# pi-famulus-darwin-arm64

The Apple Silicon macOS arm64 native manager for `pi-famulus` (`aarch64-apple-darwin`), targeting macOS 13 or newer. Your Node/pi runtime's requirements also apply. This package is built by CI and installed automatically as an exact-version optional dependency of the main package.

Install `pi-famulus`, not this package directly. There are no install hooks or external binary downloads. See the [project](https://github.com/Leechael/pi-better-subagents#readme) for installation and configuration.
