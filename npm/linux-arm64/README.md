# pi-famulus-linux-arm64

The Linux arm64 native manager for `pi-famulus`, statically linked with musl (`aarch64-unknown-linux-musl`). This package is built by CI and installed automatically as an exact-version optional dependency of the main package.

Install `pi-famulus`, not this package directly. There are no install hooks or external binary downloads. See the [project](https://github.com/Leechael/pi-better-subagents#readme) for installation and configuration.
