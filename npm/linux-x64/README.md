# pi-famulus-linux-x64

The Linux x64 native manager for `pi-famulus`, statically linked with musl (`x86_64-unknown-linux-musl`). This package is built by CI and installed automatically as an exact-version optional dependency of the main package.

Install `pi-famulus`, not this package directly. There are no install hooks or external binary downloads. See the [project](https://github.com/Leechael/pi-famulus#readme) for installation and configuration.
